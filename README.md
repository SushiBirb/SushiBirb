- **Software** — Java, TypeScript, C++20, Python, Rust. Web dashboards and full-stack systems, security automation, and ARM32 ELF reverse engineering in Ghidra.
- **Desktop** — Hyprland and Quickshell shells, GLSL shaders, and colour-synchronised theming, when the lab is behaving.
